# مخطط المخيم

أداة ويب عربية بسيطة لتحويل دليل تخطيط المخيمات إلى خطة تفاعلية قابلة للحفظ والتعديل والتصدير.

## ما الذي تتيحه الأداة؟

- تعبئة بيانات المخيم وهوية البرنامج ومراحل ما قبل المخيم وأثناءه وبعده.
- متابعة قوائم الفحص والمؤشرات وسجل التحسين.
- إضافة عناوين ونصوص وجداول مخصصة بألوان دلالية.
- حفظ تلقائي للمسودة داخل متصفح المستخدم.
- تنزيل ملف `camp.json` آمن لإعادة الاستيراد ومتابعة التعديل لاحقًا.
- تصدير الخطة إلى PDF أو Word.
- واجهة عربية بالكامل، باتجاه RTL وخط Cairo، ومتجاوبة مع الهاتف.

## الخصوصية ونطاق النسخة الأولى

لا تستخدم هذه النسخة حسابات أو قاعدة بيانات أو خدمات خلفية. تبقى بيانات الخطة في المتصفح، ولا تغادر الجهاز إلا عندما يختار المستخدم تنزيل ملف. استراتيجية بيانات المعاينة هي `NONE`.

## التشغيل المحلي

يتطلب Node.js 20 أو أحدث.

```bash
npm ci
npm run dev
```

ثم افتح [http://localhost:3000](http://localhost:3000).

## التحقق

```bash
npm run format:check
npm run lint
npm run typecheck
npm test
npm run build
```

## التقنية

- Next.js 16 / React 19 / TypeScript
- Cairo Variable Font
- `docx` لتوليد Word داخل المتصفح
- `html2canvas` و`jsPDF` لتوليد PDF داخل المتصفح

هذا المستودع هدف حقيقي مستقل لتجربة تكامل Feedback-To-Code، ولا يحتوي بيانات إنتاج أو أسرارًا أو Git remote افتراضيًا.
